RUPAK LOBBY LEDGER — GOLD EDITION

This bundle retains the original app and its Supabase integration, including
account login, lobby records, payments, QR tools, CSV export, public sharing,
and dashboard features present in the source bundle.

The visual styling has been updated with a glossy gold/dark theme.

No database reset or migration is intended for this hosting move. Reuse the
existing Supabase project and its existing VITE_SUPABASE_URL and
VITE_SUPABASE_ANON_KEY variables. Never delete the existing Supabase data.

Admin notifications, verified-badge controls, expanded profile editing and
automatic profile PDF email are NOT implemented in this bundle. They require
secure backend/admin configuration and email service setup.

Cloudflare Pages build settings for Vite:
Build command: npm run build
Build output directory: dist
